# 📖 Overview

Hyperspectral Corn Analysis is a machine learning-powered application developed to predict **vomitoxin (DON) contamination** in corn using **hyperspectral imaging**.

Instead of relying on traditional laboratory testing, which is time-consuming and destructive, this project analyzes spectral signatures collected across **448 wavelengths** and predicts contamination levels using machine learning models.

The project demonstrates how Artificial Intelligence and Computer Vision can improve food quality inspection, agricultural safety, and precision farming.

---

# 🎯 Problem Statement

Traditional methods of detecting vomitoxin contamination require:

- Laboratory testing
- High operational cost
- Sample destruction
- Long processing time

This project aims to replace these expensive procedures with an intelligent prediction system capable of delivering results within seconds.

# 🧠 Machine Learning Models

The project compares multiple machine learning algorithms to identify the best-performing model.

| Model | R² Score |
|--------|---------:|
| 🥇 Random Forest | **0.9495** |
| 🥈 Decision Tree | 0.9433 |
| 🥉 XGBoost | 0.9314 |
| Artificial Neural Network | 0.6638 |
| Linear Regression | 0.4726 |
| Support Vector Regression | -0.0376 |

### 🏆 Best Model

**Random Forest** achieved the highest prediction accuracy and was selected for deployment.
